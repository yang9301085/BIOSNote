# OpenClaw MCP 支持状态

## 结论

**当前版本（2026.3.12）OpenClaw 不支持 MCP 工具接入。**

配置文件（`openclaw.yaml` 或等效配置）中无 `tools` / `agents` / `gateway` 的 MCP 相关配置字段。

## 背景

- 安装了 `minimax-mcp-js` npm 包（支持 stdio / REST 模式）
- `minimax-mcp-js` 已就绪，等待 OpenClaw 更新或手动桥接
