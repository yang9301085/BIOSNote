### 1. ONDA_H610E SPI Flash WEN25QX128 调试 🔍 进行中

与芯片厂商（胡工）通过图片消息联合调试，进展如下：

**问题现象**：BIOS 里 Flash 驱动报 Invalid Instruction 错误

**调试过程**：

1. ✅ **移除无效指令**：`0xC7、0x60、0xB9、0x42` 从 InvalidInstruction 列表中移除（和规格书核对后确认是支持的）
2. ✅ **确认 opcode 套件**：代码默认用 `Stm_25PE` 模板（非单独新建）
   - Opcode：`Write=0x02, Read=0x03(FAST_READ=0), Erase4K=0x20, Erase64K=0xD8, ReadStatus=0x05, ReadID=0x9F, WriteStatus=0x01, WriteEnable=0x06`
3. ✅ **FAST_READ_SUPPORT 影响 Read opcode**：
   - `=0` → Read = `0x03`
   - `=1` → Read = `0x0B`
   - `=2` → Read = `0x3B`
4. 🔄 **最新修改（待上板验证）**：
   - `SPI_OPCODE_TYPE_READ_NO_ADDRESS` → 改成 `0`
   - `SPI_OPCODE_TYPE_WRITE_WITH_ADDRESS` → 改成 `3`
