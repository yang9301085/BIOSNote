## 分析方法

### 1. 从 SPI Log 提取基本信息
观察逻辑分析仪捕获的 SPI Flash 访问记录：

| 字段 | 值 | 含义 |
|---|---|---|
| 指令 | `0x0B` Fast Read | 快速读取（标准 JEDEC 指令）|
| 数据宽度 | `x1` | 单线 SPI（1-bit 模式）|
| Burst 大小 | 8行×8字节=64B | 每次 Burst 传输 64 Bytes |

### 2. Intel Flash Descriptor 布局（16MB Flash）
基于 AMI FV Map 解析：

| 区域 | 起始 | 长度 | 说明 |
|---|---|---|---|
| Descriptor | 0x00000000 | 4KB | FLMAP0-4, FCBA, VSCC 表 |
| CSE (ME/TXE) | 0x00400000 | 4MB | 管理引擎 |
| BIOS Region | 0x00400000 | ~8MB | 启动代码 |
| GbE Region | ... | ... | 千兆以太网固件 |
| Platform Data | ... | ... | OEM 数据 |

> **注意**：BIOS Region 基址 = `0x00400000`（系统内存映射地址），实际 SPI offset 需要参考 Descriptor 中的 FLMAP1。

### 3. VSCC 表验证
- VSCC 表地址：`0x00DF0 - 0x00EFF`（0x110 字节）
- WEN25QX128（JEDEC: 0xEF3017）的 VSCC 参数需与 datasheet 对比
- 若 Descriptor 中无匹配项 → PCH 会用 SFDP 探测

### 4. UEFI/FSP 启动阶段
```mermaid
flowchart TD
  PWR["上电<br/>PCH straps / Flash Descriptor"] --> RV["Reset Vector<br/>CPU 取第一条指令"]
  RV --> SEC["SEC<br/>最小固件入口"]
  SEC --> FSPT["FSP-T<br/>TempRamInit - 早期CAR初始化"]
  FSPT --> PEI["PEI<br/>Pre-EFI Initialization"]
  PEI --> FSPM["FSP-M<br/>MemoryInit - 内存初始化"]
  PEI After Memory --> FSPS["FSP-S<br/>SiliconInit - IO初始化"]
  FSPS --> DXEIPL["DXE IPL<br/>找到 FV 中的 DXE Core"]
  DXEIPL --> DXE["DXE Core<br/>驱动环境"]
  DXE --> BDS["BDS<br/>启动设备选择"]
  BDS --> RT["Runtime<br/>操作系统接管"]
```
