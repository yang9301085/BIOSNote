## 三、启动流程总览

```
SEC → PEI(FSP-T→FSP-M→PeiPciEnum→FSP-S) → DXE(PCI Bus→Nvme) → BDS → RT
```

| 阶段 | 关键模块 |
|------|----------|
| SEC | Reset Vector (0xFFFFFFF0)、MicroCode + BIST、创建 CAR |
| PEI-FSP-T | `FspTempRamEntry()` — 建立临时栈 |
| PEI-FSP-M | `FspMemoryInitEntry()` — 内存培训/DQ训练/RCOMP/HOB |
| PEI-PeiPciEnum | 早期 PCI 配置访问 |
| PEI-OemPei | SIO 配置/GPIO/电源策略 |
| PEI-FSP-S | `FspSiliconInitEntry()` — PCH/PCIe 控制器/USB/SATA |
| DXE-PciHostBridge | 安装 Root Bridge |
| DXE-PciBus | `PciEnumerateAll()` → `EnumerateBus()` ★ |
| DXE-Nvme | `NvmeBusSupported()` / `NvmeBusStart()` |
| BDS | FixedBootOrder → 启动设备选择 |

## 四、Intel FSP 架构

### 4.1 三组件职责

| 组件 | 入口函数 | 核心功能 | UPD 大小 |
|------|----------|----------|----------|
| FSP-T | `FspTempRamEntry()` | CAR 建立/临时栈 | 9KB |
| FSP-M | `FspMemoryInitEntry()` | 内存培训/DQ/RCOMP/HOB | 140KB |
| FSP-S | `FspSiliconInitEntry()` | PCH 初始化/PCIe 控制器 | 246KB |

### 4.2 FSP-M → DXE HOB 传递

```
FSP-M 输出 HOB 链表:
  ├─ gEfiMemoryTypeInformationGuid HOB → 内存类型配额
  ├─ gEfiPlatformMemorySizeGuid HOB  → 可用内存大小
  └─ gEfiVariableGuid HOB             → NVRAM 基线
      ↓
DXE/BDS 读取 → 若首启配额变化 → EfiResetCold
```

## 五、PCI Bus 枚举机制 ★★★

### 5.1 核心函数

| 函数 | 行号 | 功能 |
|------|------|------|
| `PciBusSupported()` | ~100 | Driver Binding 支持检查 |
| `PciBusStart()` | ~200 | Driver Binding 启动 |
| `PciEnumerateAll()` | ~6800 | 枚举所有 Host/Bus/Device 入口 |
| `EnumerateBus()` | **6881** ★★★ | 枚举单条 PCI 总线 |
| `PcieDoubleCheckCard()` | AmiPciExpressLib.c:117 | 二次检查卡是否存在 |
| `NewDevice()` | ~7200 | 分配 PCI_DEV_INFO 结构 |
| `InitDevData()` | ~7050 | 初始化设备 VID/DID/ClassCode |
| `PcieInitLink()` | ~7522 | 初始化 Downstream Port 链路 |
| `InstallPciDevice()` | ~10765 | 安装 PCI 设备协议 |

### 5.2 枚举时序问题 ★★★

> [!warning] NVMe 首启失败根因
> `EnumerateBus()` 的执行顺序：
> 1. 先递归扫子总线（`7407-7413`）
> 2. 后调用 `PcieInitLink()` 初始化链路（`7522-7527`）
> 3. **没有 rescan 机制**
>
> Cold Reset 后 Root Port LTSSM Training 还没完成，`0xFFFFFFFF` 直接被判定为"无设备"，设备被跳过。

### 5.3 PcieDoubleCheckCard() 二次检查机制

**代码位置**: `AmiPciExpressLib.c:117-176`

触发条件（需同时满足）：
- VID/DID 读到 `0xFFFFFFFF`
- `PcieCheckPcieCompatible(ParentBrg) = TRUE`
- `Dev == 0 && Func == 0`
- `SlotImpl == TRUE`

> [!caution] SlotImpl 问题
> M.2 插槽通常 `SlotImpl = 0`，**不满足条件，二次检查根本不走**。
> 即使 `SlotImpl = 1`，检查的是**父 Root Port 是否有 Slot**，不是 NVMe 设备本身是否训练完成。
> NVMe M.2 作为 Endpoint，`PcieInitLink()` 不会对它调用——链路训练完全依赖 Root Port 自动机制。

### 5.4 验证打点（4个关键点）

```
PciBus.c:6943-6992   EnumerateBus() 首次 VID/DID
AmiPciExpressLib.c:126-170  PcieDoubleCheckCard()
PciBus.c:7522-7527   PcieInitLink()
PciBus.c:10765-10823 InstallPciDevice()
```

## 六、BDS Reset 链机制

**代码位置**: `AmiModulePkg/Bds/Bds.c`

| 行号 | 条件 | 动作 |
|------|------|------|
| 1643-1649 | `PreviousMemoryTypeInformation` 不存在 | `IsFirstBoot=TRUE` |
