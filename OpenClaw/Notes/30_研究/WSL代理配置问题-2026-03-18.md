# WSL 代理配置问题

**状态**: 已解决
**环境**: WSL2 + Windows 代理软件
**日期**: 2026-03-18

---

## 问题描述

### 现象
- `openclaw update` 失败
- `npm install -g openclaw@latest` 也失败，无法访问 GitHub
- Windows 能正常访问 GitHub，但 WSL 不行

### 关键特征
- WSL 访问 `github.com:443` 失败
- SSH 访问 `git@github.com:22` 也失败
- Windows 通过代理访问 GitHub 正常

---

## 问题分析

### 问题链路

```
openclaw update 失败
    ↓
npm install -g openclaw@latest 失败
    ↓
WSL 访问 GitHub 不通
    ↓
代理软件只监听 127.0.0.1 (Windows 本机)
    ↓
WSL 默认够不着这个代理
```

### 根本原因

1. **OpenClaw 安装方式**: npm 全局安装版，`openclaw update` 不适用
2. **代理绑定地址**: 代理软件只监听 `127.0.0.1`，没有开放到局域网
3. **WSL 网络隔离**: WSL 的 `127.0.0.1` 和 Windows 的 `127.0.0.1` 不是同一个

### 代理端口信息

| 协议 | 端口 |
|---|---:|
| HTTP | 33210 |
| SOCKS | 33211 |

### WSL 网络信息

- WSL 默认网关: `172.29.80.1` (Windows 宿主机地址)

---

## 解决方案

### 方法 1: 直接用 127.0.0.1 (先试这个)

某些 WSL 版本支持 localhost 转发：

```bash
export http_proxy=http://127.0.0.1:33210
export https_proxy=http://127.0.0.1:33210
export all_proxy=socks5://127.0.0.1:33211
```

测试：

```bash
curl -I https://github.com
git ls-remote https://github.com/whiskeysockets/libsignal-node.git
```

如果通了，直接升级：

```bash
npm install -g openclaw@latest
```

---

### 方法 2: Windows 端口转发 (如果方法 1 不通)

#### 步骤 1: 在管理员 PowerShell 里添加端口转发

```bat
netsh interface portproxy add v4tov4 listenaddress=0.0.0.0 listenport=33210 connectaddress=127.0.0.1 connectport=33210
netsh interface portproxy add v4tov4 listenaddress=0.0.0.0 listenport=33211 connectaddress=127.0.0.1 connectport=33211
```

查看是否生效：

```bat
netsh interface portproxy show all
```

#### 步骤 2: 防火墙放行

```bat
netsh advfirewall firewall add rule name="WSL Proxy 33210" dir=in action=allow protocol=TCP localport=33210
netsh advfirewall firewall add rule name="WSL Proxy 33211" dir=in action=allow protocol=TCP localport=33211
```

#### 步骤 3: 在 WSL 里用宿主机地址

```bash
export http_proxy=http://172.29.80.1:33210
export https_proxy=http://172.29.80.1:33210
export all_proxy=socks5://172.29.80.1:33211
```

测试：

```bash
curl -I https://github.com
git ls-remote https://github.com/whiskeysockets/libsignal-node.git
npm install -g openclaw@latest
```

---

### 方法 3: 永久配置 (验证成功后)

确认能用后，写入 `~/.bashrc`：

```bash
# WSL 代理配置
export http_proxy=http://172.29.80.1:33210
export https_proxy=http://172.29.80.1:33210
export all_proxy=socks5://172.29.80.1:33211
export HTTP_PROXY=http://172.29.80.1:33210
export HTTPS_PROXY=http://172.29.80.1:33210
export ALL_PROXY=socks5://172.29.80.1:33211
```

## 关键结论

| 问题 | 结论 |
|---|---|
| `openclaw update` 失败 | 不是命令坏了，是 npm 安装版该用 npm 升级 |
| npm 升级失败 | 不是 GitHub 授权问题 |
| 根因 | WSL 和 Windows 本地代理没接上 |
| Windows 能访问 GitHub | 因为代理接管，不是裸连公网 |

---

## 注意事项

1. **先验证再永久写**: 别一开始就写 `~/.bashrc`，先确认能用
2. **WSL 网关可能变化**: 重启后 WSL 网关地址可能变，需要重新查
3. **代理软件重启**: 如果代理软件重启，可能需要重新设置端口转发
