# RevolutionBIOSUI

## 项目概述

- **类型**: UEFI BIOS 项目
- **平台**: Intel Raptor Lake（第13代酷睿）
- **BIOS 厂商**: AMI (American Megatrends)
- **框架**: EDK2 + AMI Aptio 5.x
- **主板型号**: B760M4S1

## 编译方式

```batch
SetVarEV.bat rebuild    # 完整重建
SetVarEV.bat build      # 增量构建
SetVarEV.bat clean      # 清理
```
