# 收件箱清理提示词

请整理 `8_收件箱` 中的一条笔记，并严格按下面顺序判断：

1. 这条内容是否仍然只是临时记录、待确认信息、未完成素材？
2. 它是否服务于一个明确项目交付？
3. 它是否主要是在分析问题、比较方案、排查故障？
4. 它是否已经可以抽象成稳定、可复用的知识？
5. 它是否只是链接、资料索引、工具清单？
6. 它是否属于计划、路线图、周月安排？

执行要求：

- 不确定时，保留在 `8_收件箱`。
- 有明确交付目标的，迁移到 `20_项目`。
- 有明显分析过程的，迁移到 `30_研究`。
- 只有结论足够稳定时，才迁移到 `40_知识库`。
- 如果迁移，补充推荐文件名和必要的双向链接。

输出时请包含：

- 原条目状态判断
- 推荐目录
- 推荐文件名
- 是否需要迁移
- 建议补充的链接
- 整理后的 Markdown
